# Remove Outermost Parentheses

- A valid parentheses string is defined by the following rules:
    * It is the empty string "".
    * If A is a valid parentheses string, then so is "(" + A + ")".
    * If A and B are valid parentheses strings, then A + B is also valid.

A primitive valid parentheses string is a non-empty valid string that cannot be split into two or more non-empty valid parentheses strings.

Given a valid parentheses string s, consider its primitive decomposition: s = P1 + P2 + ... + Pk, where Pi are primitive valid parentheses strings.

Return s after removing the outermost parentheses of every primitive string in the primitive decomposition of s.

|Example 1  |Example 2  |
|---------  |---------  |
|Input: s = "((()))"  |Input: s = "()(()())(())"  |
|Output: "(())"  |Output: "()()()"  |
|Explanation:  |Explanation:  |
|The input string is a single primitive: "((()))".  |Primitive decomposition: "()" + "(()())" + "(())"  |
|Removing the outermost layer yields: "(())".  |After removing outermost parentheses: "" + "()()" + "()"  |
|  |Final result: "()()()".  |

- Constraints :
    * 1 <= s.length <= 10⁵
    * s[i] is either '(' or ')'
    * s is a valid parentheses string

## Approach :

- Initialize an empty string or list to store the result.

- Use a counter variable to track the current balance of parentheses.

- Traverse the input string character by character.

- For each '(':

    * If counter > 0, append '(' to the result (it's not outermost).

    * Increment the counter.

- For each ')':

    * Decrement the counter.

    * If counter > 0, append ')' to the result (it's not outermost).

- After traversing the entire string, return the result as the new string with outermost parentheses removed.

```Java
class Solution {
    // Function to remove outermost parentheses from every 
    // primitive in a valid parentheses string
    public String removeOuterParentheses(String s) {
        // Initialize result string builder
        StringBuilder res = new StringBuilder();

        // Initialize balance counter
        int balance = 0;

        // Traverse input string
        for (char c : s.toCharArray()) {
            // If opening bracket
            if (c == '(') {
                // Append if not outermost
                if (balance > 0) res.append(c);
                // Increment balance
                balance++;
            } else { // closing bracket
                // Decrement balance
                balance--;
                // Append if not outermost
                if (balance > 0) res.append(c);
            }
        }

        // Return result string
        return res.toString();
    }
}

// Driver code
public class Main {
    public static void main(String[] args) {
        Solution sol = new Solution();
        String s = "(()())(())";
        System.out.println(sol.removeOuterParentheses(s)); // Output: ()()()
    }
}
```

## Complexity Analysis :

- Time Complexity: O(n)
- Space Complexity: O(n)
