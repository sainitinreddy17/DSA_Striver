# Longest Palindromic Substring

Given a string s, return the longest palindromic substring in s.

A palindromic substring is a contiguous sequence of characters within the string that reads the same forward and backward.

|Example 1  |Example 2  |
|---------  |---------  |
|Input: s = "babad"  |Input: s = "cbbd"  |
|Output: "bab"  |Output: "bb"  |
|Explanation:  |Explanation:  |
|Both "bab" and "aba" are valid palindromic substrings of length 3. Return either.  |The longest palindrome is "bb" of length 2.  |

- Constraints :
    * 1 <= s.length <= 1000
    * s consists of only English letters (both lowercase and uppercase) and digits.

## Approach :

- Iterate through each index of the string, treating it as the center of a potential palindrome.

- For each center, expand outward in both directions to check for palindrome symmetry.

- Consider both odd-length (center is a character) and even-length (center is between two characters) palindromes.

- Keep track of the longest palindrome found by storing its start and end indices.

- After checking all centers, extract and return the substring corresponding to the maximum length palindrome.

```Java
// Definition and Solution class
class Solution {

    // Helper function to expand around a center
    private int[] expandAroundCenter(String s, int left, int right) {
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        return new int[]{left + 1, right - 1};
    }

    // Function to return longest palindromic substring
    public String longestPalindrome(String s) {
        int n = s.length();
        if (n == 0) return "";

        int start = 0, end = 0;

        // Iterate through each index as potential center
        for (int i = 0; i < n; i++) {
            // Odd-length palindrome
            int[] odd = expandAroundCenter(s, i, i);
            // Even-length palindrome
            int[] even = expandAroundCenter(s, i, i + 1);

            // Update longest palindrome
            if (odd[1] - odd[0] > end - start) {
                start = odd[0];
                end = odd[1];
            }
            if (even[1] - even[0] > end - start) {
                start = even[0];
                end = even[1];
            }
        }

        return s.substring(start, end + 1);
    }
}

// Driver class
public class Main {
    public static void main(String[] args) {
        Solution sol = new Solution();
        String s = "babad";
        System.out.println(sol.longestPalindrome(s)); // Output: "bab" or "aba"
    }
}
```

## Complexity Analysis :

- Time Complexity: O(n²)
- Space Complexity: O(1)
