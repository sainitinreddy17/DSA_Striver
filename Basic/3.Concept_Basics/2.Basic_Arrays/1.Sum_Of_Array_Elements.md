# Sum of Array Elements

Given an array arr of size n, the task is to find the sum of all the elements in the array.

|Example 1  | Example 2 |
|---------  |-----------  |
|Input: n=5, arr = [1,2,3,4,5]  |Input: n=6, arr = [1,2,1,1,5,1]  |
|Output: 15  |Output: 11  |
|Explanation: Sum of all the elements is 1+2+3+4+5 = 15  |Explanation: Sum of all the elements is 1+2+1+1+5+1 = 11  |

- Constraints
    1 <= n <= 105
    1 <= arr[i] <= 104

## Approach : 

- Initialize a variable to zero to store the sum.

- Iterate through the array, adding each element to the sum.

- Return the sum after the loop completes.

```Java
class Solution {
    // Function to get the sum of array elements
    int sum(int arr[], int n) {
        int ans = 0; // to store the answer
        
        // Iterate on all the elements
        for (int i = 0; i < n; i++) {
            // Add the current element to the sum
            ans = ans + arr[i];
        }

        // Return the result
        return ans;
    }
}

// Main class
public class Main {
    public static void main(String[] args) {
        int n = 4;
        int arr[] = {1, 2, 3, 8};

        // Creating an instance of solution class
        Solution sol = new Solution();

        // Function call to get the sum of array elements
        int result = sol.sum(arr, n);

        // output the result
        System.out.println("The sum of array elements is: " + result);
    }
}
```

## Complexity Analysis : 

- Time Complexity : O(N)
- Space Complexity : O(1)
