# Check for Prime Number

You are given an integer n. You need to check if the number is prime or not. Return true if it is a prime number, otherwise return false.
A prime number is a number which has no divisors except 1 and itself.

|Example 1  |Example 2  |
|----------  |------------  |
|Input: n = 5  |Input: n = 8  |
|Output: true  |Output: false  |
|Explanation: The only divisors of 5 are 1 and 5 , So the number 5 is prime.  |Explanation: The divisors of 8 are 1, 2, 4, 8, thus it is not a prime number.  |

- Constraints
    1 <= n <= 5000

## Approach : 

- Check if the given number is less than 2; if yes, return false (not prime).

- Loop through all numbers from 2 to one less than the given number.

- For each number in the loop, check if it divides the given number exactly.

- If a divisor is found, return false (not prime).

- If no divisor is found after the loop, return true (the number is prime).

```Java
class Solution {

    /* Function to find whether the
    number is prime or not */
    public boolean isPrime(int n) {
        // Edge case
        if (n < 2) return false;

        // Loop from 2 to n-1
        for (int i = 2; i < n; ++i) {

            // Check if i is a divisor
            if (n % i == 0) {
                return false;
            }
        }

        // Return true as the number is prime
        return true;
    }
}

class Main {
    public static void main(String[] args) {
        int n = 5;

        /* Creating an instance of 
        Solution class */
        Solution sol = new Solution();

        /* Function call to find whether the
        given number is prime or not */
        boolean ans = sol.isPrime(n);

        if (ans) {
            System.out.println(n + " is a prime number.");
        } else {
            System.out.println(n + " is not a prime number.");
        }
    }
}
```

## Complexity Analysis : 

- Time Complexity: O(N) 
- Space Complexity: O(1)
